# Магазин "КоSметичка"
Full-stack система для магазина, продающего косметику, с панелью для администрирования, динамическими атрибутами товаров, корзиной и оформлением заказа.

## О проекте
Pet-проект, представляющий собой полноценный интернет-магазин с двумя независимыми частями:
1) Публичная часть - витрина для покупателей
2) Часть для администрирования - для управления всем ассортиментом

Проект реализован как полноценное full-stack приложение с четким разделением ответственности между клиентской и серверной частями, аутентификацией через JWT-токены (access + refresh), отправкой писем на почту и файловым хранилищем MinIO для изображений.

## Что реализовано
**Витрина**
- Каталог товаров по категориям с фильтрацией (по бренду, цене, названию и прочим атрибутам категории), пагинацией и сортировкой
- Поиск товаров по названию/артикулу
- Карточка товара с полным его описанием и характеристиками
- Корзина с изменением количества товара на позиции и лимитом по остатку на складе
- Оформление заказа с отправкой чека на почту
- Регистрация, вход, восстановление пароля по Email, профиль пользователя
- Новости, акции, контакты магазина, формы обращений (Вопрос клиента + Заявка поставщика)

**Панель для администрирования**
- CRUD категорий с динамическими атрибутами (числовые, текстовые + список вариантов)
- CRUD товаров с привязкой к категории, атрибутам и фото
- CRUD брендов, новостей и акций
- Управление пользователями (изменение роли пользователя + удаление пользователя) и обращениями (смена статуса)
- Фильтрация и постраничная навигация во всех списках

## Используемые технологии
**Frontend**:
- React + TypeScript
- Next.js (App Router)
- Mantine UI
- TanStack Query
- React Hook Form + zod (для валидации)
- Axios
- openapi-typescript (для генерации типов из OpenAPI-схемы бэкенда)

**Backend**:
- Java + Spring Boot
- Spring Security + JWT (access/refresh-токены)
- Hibernate + Spring Data JPA
- PostgreSQL
- MinIO (для хранения изображений)
- Springdoc OpenAPI (для спецификации в Swagger UI)
- JavaMailSender (для отправки писем на почту: восстановление пароля, отчет по заказу)

**Инфраструктура**:
- Docker Compose (для PostgreSQL, MinIO и бэкенда)
- Git

## Инструкция по запуску проекта
### 1. Клонировать репозиторий
```bash
git clone https://github.com/anufrievalex2006/KoSmetichka-Shop.git
cd KoSmetichka-Shop
```
### 2. Настроить переменные окружения
Создайте файл `.env` в корне проекта (рядом с `docker-compose.yml`) со следующими переменными:
```
DB_PASSWORD=
MINIO_ROOT_USER=
MINIO_ROOT_PASSWORD=
JWT_SECRET=
MAIL_USERNAME=
MAIL_PASSWORD=
FRONTEND_URL=http://localhost:3000
```
P.S. `JWT_SECRET` — произвольная base64-строка достаточной длины. `MAIL_USERNAME`/`MAIL_PASSWORD` — учётные данные почтового ящика для отправки писем (восстановление пароля, отчёт по заказу).
### 3. Запустить контейнер с бэкендом, PostgreSQL и MinIO
```bash
docker-compose up -d --build
```
Backend будет доступен по адресу `http://localhost:8080`, Swagger UI — по `http://localhost:8080/swagger-ui.html`, консоль MinIO — по `http://localhost:9001`.
### 4. Настроить Frontend
Создайте файл .env.local в папке `frontend`:
```
NEXT_PUBLIC_API_URL=http://localhost:8080/api
```
Затем:
```bash
cd frontend
npm install
npm run dev
```
Приложение будет доступно по адресу `http://localhost:3000`
